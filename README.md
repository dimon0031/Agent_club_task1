# Тусовка

Нічна афіша на Django. Знайдіть публічну подію за назвою або перейдіть за приватним запрошенням. У каталозі одразу видно, скільки місць залишилося.

![Діджейка біля пульта в червоному сценічному світлі](events/static/events/night.webp)

## Локальний запуск

Для Linux або WSL потрібні Git, Python 3.14 і модуль `venv`. Виконайте команди в одній оболонці.

```sh
git clone https://github.com/dimon0031/Agent_club_task1.git
cd Agent_club_task1
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
export DJANGO_DEBUG=1
python manage.py migrate
python manage.py runserver
```

Відкрийте [локальну афішу](http://127.0.0.1:8000/). Перший запуск створює порожню базу SQLite. Зареєструйтеся за email і натисніть **Створити подію**, щоб додати перший запис.

## Що можна зробити

| Хто | Можливості |
| --- | --- |
| Гість | Знайти майбутню публічну подію, переглянути обкладинку, дату, коментарі та вільні місця. Відкрити приватну подію за запрошенням. |
| Учасник | Записатися кнопкою **Іду**, скасувати участь, залишити коментар і повернутися до своїх подій через профіль. |
| Автор | Створити подію, завантажити обкладинку, вибрати видимість і місткість. Редагувати подію, переглянути список учасників або видалити її з підтвердженням. |

Автор автоматично займає одне місце. Скасування повертає його до загального залишку. Після початку події запис закривається. Дата і час у формах вказуються за Києвом.

На головній можна призупинити відеоафішу. Кнопка **♫ Музика** вмикає фоновий трек і запам’ятовує вибір. Перший візит починається без звуку.

## Перевірка

Після встановлення залежностей усі тести запускаються однією командою з кореня репозиторію. Django створює для них окрему базу.

```sh
DJANGO_DEBUG=1 .venv/bin/python manage.py test
```

[Приймальний тест із двома акаунтами](events/test_acceptance.py) проходить шлях від створення приватної події до видалення. Гість реєструється за запрошенням, займає останнє місце, залишає коментар і скасовує участь. Автор бачить учасника й коментар. Після видалення старе посилання пропонує повернутися до афіші.

Щоб запустити лише цей сценарій:

```sh
DJANGO_DEBUG=1 .venv/bin/python manage.py test events.test_acceptance
```

Інші тести перевіряють одночасні заявки на останнє місце, повторний запис, захист приватних подій та обкладинок, права автора, пошук і помилки введення.

## Налаштування середовища

| Змінна | Призначення |
| --- | --- |
| `DJANGO_DEBUG` | `1` для локального запуску. За замовчуванням режим налагодження вимкнений. |
| `DJANGO_SECRET_KEY` | Секрет для підпису даних. У локальному режимі є ключ для розробки. Для розгортання задайте окремий випадковий секрет. |
| `DJANGO_ALLOWED_HOSTS` | Дозволені хости через кому. Типове значення підтримує локальні адреси. |
