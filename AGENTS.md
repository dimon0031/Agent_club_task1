# Інструкції користувача для «Тусовки»

- Розробляємо застосунок на Django із серверними HTML-шаблонами та SQLite для локального запуску.
- При створенні події автоматично записуємо автора як учасника. Автор може редагувати свою подію.
- Записуй сюди нові інструкції користувача щодо подальшої роботи над проєктом. Коли користувач змінює попередню домовленість, оновлюй відповідний пункт.

План реалізації та стан виконання ведемо у [PLAN.md](PLAN.md).
